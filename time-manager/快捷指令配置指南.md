# 时间管家 - iPhone 快捷指令配置指南

## 一、手机调试访问

1. 确保手机和电脑连接**同一个WiFi**
2. iPhone 用 Safari 打开：
   ```
   http://192.168.100.197:8888
   ```
3. 测试功能正常后，点 Safari 底部「分享」→「添加到主屏幕」
4. 桌面出现「时间管家」图标，点开即全屏App体验

---

## 二、配置「解锁自动弹出」快捷指令

### 步骤 1：创建个人自动化

1. 打开 iPhone 自带的「快捷指令」App
2. 底部切换到「自动化」标签
3. 点右上角「+」→「创建个人自动化」

### 步骤 2：选择触发条件

1. 向下滑动找到「iPhone 已解锁」
2. 点「下一步」

### 步骤 3：添加操作（按顺序添加以下3个）

#### 操作1：选择办公软件

- 点「添加操作」
- 搜索「从列表中选取」
- 点进去，在「列表」中输入你的办公软件，每行一个：
  ```
  微信
  钉钉
  Word
  Excel
  PPT
  浏览器
  邮件
  会议
  其他
  ```
- 「提示」填写：`现在要用哪个办公软件？`

#### 操作2：选择使用时长

- 点「+」添加下一个操作
- 搜索「从列表中选取」
- 列表填写：
  ```
  15
  30
  45
  60
  90
  120
  ```
- 「提示」填写：`使用多少分钟？`

#### 操作3：打开时间管家并自动开始计时

- 点「+」添加下一个操作
- 搜索「打开URL」
- URL 填写（注意把下面的中文替换成变量）：
  ```
  http://192.168.100.197:8888/index.html?action=start&app=[选取的项目]&duration=[选取的项目]
  ```
  - 输入 `app=` 后，点键盘上方的「选取的项目」变量（来自第一个列表操作）
  - 输入 `duration=` 后，点键盘上方的「选取的项目」变量（来自第二个列表操作）

### 步骤 4：关闭运行前询问

1. 点「下一步」
2. **关闭**「运行前询问」开关
3. 点「完成」

---

## 三、效果

每次解锁 iPhone，会自动弹出：
1. 选择办公软件的列表
2. 选择使用时长的列表
3. 自动打开时间管家并开始倒计时
4. 时间到自动记录并发送通知提醒

---

## 四、注意事项

1. **同一WiFi**：手机和电脑必须连同一个WiFi，否则访问不到
2. **IP变化**：电脑重启后IP可能变，用 `ipconfig` 查看当前IP，更新快捷指令中的URL
3. **建议固定IP**：在路由器管理页面给电脑设置静态IP绑定，一劳永逸
4. **后台计时**：PWA在后台时倒计时仍会通过本地通知提醒，时间到自动记录
5. **数据存储**：所有记录存在手机本地（Safari/PWA的localStorage），不会上传

---

## 五、常见问题

**Q：快捷指令打开的是Safari而不是桌面App？**
A：先在Safari打开网址并「添加到主屏幕」，之后快捷指令打开同一URL会自动进入全屏App模式。

**Q：电脑关机了还能用吗？**
A：计时和统计功能可以离线使用（PWA已缓存），但快捷指令通过URL启动需要电脑开着服务器。可以把PWA部署到免费静态托管（如GitHub Pages、Vercel）实现永久在线。

**Q：怎么看统计数据？**
A：打开时间管家 → 底部「统计」标签 → 切换日/周/月视图。
